# Obsidian Vault → RAG → Publish

1. Markdown-протоколы в `vault/protocols`
2. Чанкинг и хеш-эмбеддинги → FAISS
3. DeepSeek формирует ответы для раздельных контуров РФ и INT
4. Веб-поиск проверяет официальные российские и международные источники
5. Кандидаты фиксируются в `source_registry.json` и не загружаются автоматически
6. Медицинский материал попадает в RAG только после проверки человеком

## Российские КР по неврологии и нейрохирургии

Каталог `guidelines/rf` содержит 17 официальных карточек Минздрава, синхронизированных
из реестра портала. В локальный RAG загружены только название, профиль, коды МКБ,
версия, год и официальная ссылка (`content_scope=bibliographic_metadata_only`).
Эти карточки используются для поиска нужной КР и заполнения заголовка карточки Vitalis,
но не считаются доказательством диагностики, лечения, дозировок или класса рекомендаций.
Медицинские фрагменты система получает отдельно из полного текста на разрешённом
официальном домене и помечает `full_text_checked=true` только после успешного извлечения.

Три файла в `vault/protocols` — демонстрационные локальные конспекты. Их нельзя считать
полными копиями официальных рекомендаций или использовать как единственное основание
клинического решения; перед пилотом они требуют сверки с реестром первоисточников.

# Obsidian Vault → RAG → Publish

1. Проверенные полные тексты клинических рекомендаций
2. Deny-by-default фильтр, чанкинг и хеш-эмбеддинги → FAISS
3. DeepSeek формирует ответы для раздельных контуров РФ и INT
4. Веб-поиск проверяет официальные российские и международные источники
5. Кандидаты фиксируются в `source_registry.json` и не загружаются автоматически
6. В RAG попадает только проверенный полный текст клинической рекомендации

## Российские КР по неврологии и нейрохирургии

Каталог `guidelines/rf` содержит 17 официальных карточек Минздрава, синхронизированных
из реестра портала. Они имеют `content_scope=bibliographic_metadata_only` и используются
только для обнаружения КР и заполнения метаданных карточки.

Проверенные полные тексты загружаются отдельно в игнорируемый Git каталог
`generated/guidelines/rf`. Импорт допускает только точный официальный endpoint,
проверяет PDF, название и код МКБ, сохраняет SHA-256 и разбивает текст с номерами
страниц. Такие документы имеют `content_scope=official_full_text_extracted`.

Статьи портала и заметки Life-OS могут физически сохраняться в legacy-каталогах для
аудита, но всегда исключаются из индекса. Их редактура или публикация не меняет это
правило.

Три файла в `vault/protocols` — демонстрационные локальные конспекты. Они не являются
полными копиями официальных рекомендаций и не индексируются.

Подробности: `docs/RF_GUIDELINES_FULLTEXT.md` и `docs/LIFEOS_RAG_INTEGRATION.md`.

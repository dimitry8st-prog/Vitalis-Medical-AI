# Vitalis — текущая контрольная точка

Дата: 2026-11-07.

## Где находится реальный Life-OS

Фактическая база Life-OS относится к порталу `st8dom-site`, а не к демонстрационному
vault репозитория `Life-Os`. Данные могут находиться в трёх местах:

1. runtime-БД портала: `LifeOSMaterial`, а проверенные статьи — `Article` и
   `ArticleSource`;
2. `st8dom-site/data/content-packages/`;
3. `st8dom-site/obsidian-vault/`.

`Life-Os/data/demo-vault` используется только для демонстрации механики. Нулевой импорт
из него ничего не говорит о фактических материалах, добавленных Дмитрием сегодня.

## Что уже выполнено

- безопасный импорт полного текста российских КР;
- deny-by-default адаптер заметок;
- read-only экспортёр проверенных публикаций из `st8dom-site`;
- импорт экспортированных публикаций портала с SHA-256, проверкой рецензирования,
  PII и prompt injection;
- page-aware RAG и приоритет официального первоисточника;
- проверка ссылок и точных дозировок;
- fail-closed production-gate;
- локальная база портала экспортировала и импортировала 10/10 проверенных статей,
  отклонённых записей нет;
- локальная карточка Vitalis проверена по мигрени, реабилитации после ишемического
  инсульта и ботулинотерапии при орофациальной боли;
- 130 Python-тестов Vitalis, 4 Node-теста, CI-lint и dependency audits проходят;
- 307 тестов `st8dom-site` проходят; GitHub CI PR #17 ранее прошёл.

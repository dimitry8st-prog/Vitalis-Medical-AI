# Международный контур поиска Vitalis

## Назначение

Международный контур ищет только клинические рекомендации и не смешивает их с
российским контуром. Он не назначает лечение и сохраняет решение за врачом.

## Допустимые источники

1. Официальные клинические руководства WHO и международных органов здравоохранения.
2. Официальные руководства профильных обществ и государственных систем Европы,
   Великобритании, США, Канады и Австралии.
3. Национальные клинические рекомендации других стран, если они прямо относятся к
   вопросу и их версия подтверждена.

Регуляторные инструкции, отдельные исследования, систематические обзоры, PubMed,
Europe PMC, новости и пересказы не передаются в контекст ответа как рекомендации.

## Поисковый процесс

1. Из запроса выделяются диагноз/нозология, клиническая цель, код МКБ и английский
   термин.
2. Строятся отдельные запросы к WHO, NICE и профильным обществам по теме.
3. Каждый результат классифицируется; всё, что не является клинической рекомендацией,
   исключается.
4. Российские и неизвестные домены исключаются из международной выдачи.
5. Для allowlist-источника система пытается получить полный HTML или PDF и выделить
   ограниченный релевантный фрагмент.
6. В генератор передаётся только результат с `document_type=clinical_guideline`,
   `full_text_checked=true` и непустым `evidence_excerpt`.
7. Если полный текст получить не удалось, строгий режим блокирует доказательный ответ
   либо явно сообщает об ограничении в warn-режиме.

## Дозировки

Точная доза, путь введения и продолжительность могут быть приведены только при буквальном
подтверждении в проверенном фрагменте полного текста клинической рекомендации выбранной
юрисдикции. Данные между странами автоматически не переносятся.

## Метаданные результата

- `jurisdiction` — страна или регион;
- `document_type=clinical_guideline` — обязательная классификация;
- `official_domain` — официальный первичный домен;
- `full_text_checked` — полный текст успешно получен;
- `retrieved_at` — время получения;
- `evidence_excerpt` — ограниченный фрагмент полного текста.

## Проверка

```bash
PYTHONPATH=backend python -m unittest \
  backend/tests/test_web_search_queries.py \
  backend/tests/test_search_integration.py -v
```

Обязательные сценарии: разделение RU/INT, отсутствие PubMed/регуляторных запросов,
отклонение неизвестных доменов, исключение результата без полного текста и поиск по
диагнозу, МКБ и свободному вопросу.

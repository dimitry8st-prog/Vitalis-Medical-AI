# Vitalis Documents — безопасный разбор медицинских PDF

Дата реализации MVP: 21 октября 2026 года.

## Назначение и границы

Модуль помогает врачу ориентироваться в уже существующем документе: извлекает текст,
показывает явно записанные диагнозы, показатели, лекарства и другие сведения, а затем
отвечает на вопросы только по этому тексту.

Модуль не ставит диагноз, не назначает и не отменяет лечение, не добавляет документ в RAG
и не смешивает его содержание с клиническими рекомендациями. Сравнение с контурами РФ и
INT должно оставаться отдельным, явно запускаемым врачом процессом.

## Поток данных

1. Пользователь подтверждает, что PDF синтетический или заранее обезличенный.
2. FastAPI принимает файл с жёсткими лимитами размера и типа.
3. Валидатор проверяет `%PDF-`, шифрование, число страниц, активные действия, JavaScript,
   XFA и вложения.
4. `pypdf` извлекает текст отдельно для каждой страницы.
5. Детерминированный redactor скрывает распространённые идентификаторы.
6. Детектор помечает возможные инструкции, направленные на модель.
7. Только при чистой проверке и явной серверной настройке обезличенные страницы могут быть
   переданы внешней модели.
8. Pydantic проверяет JSON-ответ. Каждый evidence-пункт сохраняется только тогда, когда его
   цитата реально присутствует на указанной странице.
9. В памяти процесса создаётся случайная временная сессия. Исходные байты PDF не переносятся
   в базу приложения; временный upload закрывается после обработки.
10. Пользователь удаляет сессию кнопкой или она автоматически истекает по TTL.

## Режимы

| Режим | Условие | Поведение |
|---|---|---|
| `mock` | внешний анализ выключен | локальное извлечение размеченных строк и показателей |
| `live` | DeepSeek настроен и `DOCUMENT_EXTERNAL_LLM_ENABLED=true` | структурированный анализ обезличенного текста |
| `disabled` | найден остаточный PII, prompt injection или опасный вопрос | внешний вызов запрещён, остаётся локальная обработка |

## API

### Загрузить и разобрать

`POST /documents/analyze`, `multipart/form-data`:

- `file`: PDF;
- `confirmed_deidentified=true`.

Ответ содержит `session_id`, время истечения, число страниц, отчёты PII/security и
структурированный анализ.

### Задать вопрос

`POST /documents/{session_id}/questions`:

```json
{"question":"Какой показатель указан на второй странице?"}
```

Ответ ограничен текстом документа и содержит постраничные цитаты.

### Удалить

`DELETE /documents/{session_id}`.

## Настройки

```dotenv
DOCUMENT_ANALYSIS_ENABLED=true
DOCUMENT_EXTERNAL_LLM_ENABLED=false
DOCUMENT_MAX_FILE_BYTES=8000000
DOCUMENT_MAX_PAGES=40
DOCUMENT_MAX_CHARS=80000
DOCUMENT_PARSE_TIMEOUT_SECONDS=20
DOCUMENT_SESSION_TTL_SECONDS=1800
DOCUMENT_MAX_SESSIONS=32
DOCUMENT_REQUIRE_DEIDENTIFIED_CONFIRMATION=true
```

## Ограничения MVP

- OCR не выполняется; скан без текстового слоя отклоняется.
- Автоматическое обезличивание не гарантирует удаление всех возможных идентификаторов.
- Сессии находятся в памяти одного процесса и исчезают при перезапуске.
- Сессия защищена случайным токеном, но в MVP не привязана к отдельной учётной записи;
  многопользовательский запуск требует аутентификации и проверки владельца сессии.
- Сравнение с рекомендациями РФ/INT не запускается автоматически.
- Перед использованием реальных данных необходимы правовая проверка, договорные условия
  провайдера, модель угроз, политика хранения и отдельная клиническая оценка.

## Проверка перед пилотом

- запускать тесты только на синтетических PDF;
- проверить повреждённые, большие, зашифрованные и активные PDF;
- проверить PII-шаблоны и prompt injection на русском и английском языках;
- убедиться, что невалидные цитаты модели удаляются;
- проверить ручное удаление и истечение TTL;
- не включать внешний LLM до отдельного решения владельца проекта.

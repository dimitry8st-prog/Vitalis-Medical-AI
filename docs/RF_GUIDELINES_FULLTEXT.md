# Полные тексты КР РФ в RAG Vitalis

## Назначение

Vitalis загружает 17 российских клинических рекомендаций по неврологии и
нейрохирургии из реестра портала и получает PDF только через официальный endpoint
Минздрава. Полные тексты являются локальными runtime-данными и не публикуются в Git.

## Безопасный импорт

Импорт выполняется отдельной командой, а не во время пользовательского запроса:

```bash
PYTHONPATH=backend python -m app.rag.minzdrav_fulltext sync \
  ../st8dom-site/data/clinical_guidelines.json vault \
  --authorized-by "Ответственный за клиническую базу" \
  --authorized-at 2026-11-07
```

Для каждого документа система:

1. принимает только `https://apicr.minzdrav.gov.ru/API.ashx` с операцией
   `GetClinrecPdf` и ожидаемым идентификатором КР;
2. проверяет каждый redirect, лимитирует размер и время загрузки;
3. отклоняет ответ без PDF-сигнатуры;
4. извлекает текст в отдельном процессе без API-ключей;
5. проверяет минимальный объём, название КР и хотя бы один ожидаемый код МКБ;
6. сканирует текст на недоверенные инструкции;
7. сохраняет SHA-256, количество страниц, URL карточки и URL документа;
8. размечает каждый фрагмент номером страницы.

Результат сохраняется в `vault/generated/guidelines/rf/`. Этот каталог исключён из
Git. `manifest.json` показывает полноту синхронизации. При временной ошибке ранее
проверенный документ сохраняется, а синхронизация получает статус `partial`; такой
статус не проходит production-gate.

## Использование в ответе

Полный текст получает `document_type=clinical_guideline_full_text`,
`content_scope=official_full_text_extracted` и `full_text_checked=true`. Только такой
документ индексируется. Фрагмент передаётся модели с меткой `[Страница N]`. Точная
дозировка разрешается пост-проверкой только когда она буквально присутствует в
найденном фрагменте официального первоисточника.

Карточка «Препараты и дозировки» дополнительно требует `guideline_status=active`,
`source_version` и `current_version_checked_at`. Проверка действующей версии должна
быть не старше 45 дней. Строка карточки является дословным фрагментом КР и содержит
страницу PDF, версию, официальный URL и дату проверки. Модель не пересчитывает дозы,
не переносит режим между группами пациентов и не объединяет части режима из разных КР.
Возраст публикации сам по себе не отменяет КР: если официальный статус действующей
версии повторно подтверждён, документ остаётся допустимым.

`bibliographic_metadata_only` остаётся поисковой карточкой для обнаружения документа,
но не входит в FAISS и не подтверждает лечение, диагностику, доказательность или
дозировки. Статьи портала и заметки Life-OS также не индексируются.

## Проверка

```bash
PYTHONPATH=backend python -m unittest backend/tests/test_minzdrav_fulltext.py -v
PYTHONPATH=backend python - <<'PY'
from pathlib import Path
from app.rag.vault import VaultRAG

rag = VaultRAG(Path("vault"), Path("/tmp/vitalis-rag-check"))
print("chunks:", rag.build())
for hit in rag.search("лечение мигрени G43", k=3):
    print(hit["title"], hit["path"], hit["text"][:80])
PY
```

Перед выпуском дополнительно проверяется обычный путь `/ask`, а не только прямой поиск
по FAISS. Выполняются три запроса: название диагноза, код МКБ и произвольный клинический
вопрос. Карточка должна показать код МКБ, официальный URL, число страниц, SHA-256 и
метку «полный текст проверен».

## Ограничение

Техническая проверка происхождения и целостности документа не заменяет клиническую
экспертизу содержания. Production-пилот допускается только после слепой оценки
синтетического набора профильным врачом и прохождения release-gate.

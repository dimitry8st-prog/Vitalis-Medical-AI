Publish

Внутренняя база команды

Vault

Единый источник истины для разработчиков, медицинских экспертов и контент-менеджеров.

  • Архитектурные решения (ADR)
  • Протоколы ревью медицинского контента
  • Граф связей между нозологиями
  • Заметки по API и интеграциям

Источник данных для RAG

Pipeline

Markdown-формат Obsidian идеально ложится на пайплайн LangChain.

  • vault/*.md → чанкинг → эмбеддинги
  • FAISS-индекс обновляется при git push
  • Метаданные YAML → фильтрация по нозологии
  • Версионирование через Git

Три режима работы в одной платформе

Каждый режим имеет собственную границу источников и не смешивает документы между собой.

Поиск по клиническим рекомендациям

Запрос может быть диагнозом, кодом МКБ или клиническим вопросом. В ответ попадают только проверенные фрагменты полных рекомендаций с источником и страницей.

Что указано в действующей КР по профилактике мигрени? · G43
📄

Разбор медицинского PDF

Vitalis извлекает текст по страницам, удаляет распространённые идентификаторы и отвечает только по загруженному документу. PDF не становится частью RAG.

Разбор страхового договора / полиса

Система выделяет тип страхования, покрытие, исключения, лимиты и порядок обращения. При отсутствии условий ищет общую справку только на официальном сайте распознанного страховщика.

Архитектура знаний

Контролируемая база источников

Vitalis отделяет обнаружение документа от его допуска. Карточка, статья или поисковый фрагмент не становятся медицинским доказательством.

📓

Официальный полный текст

Клиническая рекомендация загружается из разрешённого первичного источника и сохраняется вместе с версией, страницами и SHA-256.

Source
⚡

Фильтр допуска → FAISS

В индекс попадает только документ со строгими метаданными полного текста. Поиск усиливается совпадением диагноза и кода МКБ.

RAG
🧠

Ответ только по доказательствам

Релевантные фрагменты передаются в контекст вместе со страницами. Неподтверждённые ссылки и точные дозы блокируются.

Evidence
🌐

Отказ при нехватке данных

Если полный текст недоступен или проверка источника не пройдена, Vitalis сообщает об ограничении и не подменяет рекомендацию пересказом.

Fail closed

Граница знаний

Policy

Vitalis RAG принимает только проверенные полные тексты клинических рекомендаций.

  • Статьи портала не индексируются
  • Заметки Life-OS не индексируются
  • Карточки метаданных служат только для обнаружения
  • Российский и международный контуры разделены

Источник данных для RAG

Pipeline

Загрузка и обновление проходят через проверяемый конвейер.

  • Официальный PDF → безопасное извлечение
  • Проверка названия и кодов МКБ
  • Чанкинг с сохранением номера страницы
  • Контролируемая перестройка FAISS и версия в Git

Проверяемый результат

Output

Ответ остаётся справочным и показывает врачу, на чём основано каждое положение.

  • Название и версия рекомендации
  • Организация и юрисдикция
  • Страница и официальный URL
  • Явные ограничения и отказ при нехватке данных
